# event-timeslot-0907 — 팀원이 직접 입력하는 항목

`event-timeslot-0828`의 다음 버전. **대표자가 팀원 정보를 전부 대신 적던 것을, 이름·전화번호만 적고
나머지는 팀원이 동의 화면에서 직접 채우도록** 바꿨다.

## 왜

대표자가 팀원의 학과·학번을 대신 적으면 틀리기 쉽고, 애초에 모르는 경우도 많다.
팀원에게는 어차피 동의 알림톡이 나가므로, 그 화면에서 본인이 채우는 것이 정확하다.

## 무엇이 바뀌었나

### 이벤트 만들기 (`event-input.html`)

`팀원 동의받기` 블록에 **팀원이 직접 입력** 질문 목록이 생겼다. 동의 내용·동의 마감 아래에 붙는다.

```
신청폼
  팀 정보      팀 이름 …
  팀원 정보    이름 · 전화번호 · 이메일        ← 그대로

자리 배정      [토글]

팀원 동의받기  [토글]
  동의 내용
  동의 마감
  팀원이 직접 입력    ← 새로 생긴 것
    학번 · 학과 · 사연 + 질문 추가
```

- 신청폼 쪽은 손대지 않았다. 묶음 제목도, 항목을 옮기는 메뉴도 없다.
- 필수/선택은 신청폼 질문과 똑같이 동작한다.
- 동의받기를 끄면 이 목록도 숨는다. 만든 질문은 지워지지 않고, 다시 켜면 그대로 있다.
- **한 블록이 곧 한 화면**이다 — 신청폼은 신청 화면, 팀원 동의받기는 동의 화면.

### 참가자 화면 (`event-landing.html`)

- **신청 화면** — 팀원 카드에 이름·전화번호만 남았다. 전화번호는 동의 알림톡을 보내야 하므로 필수로 고정.
- **동의 화면** — 동의 내용 아래에 본인이 채울 항목이 나온다. 필수를 비우면 `참석 동의하기`가 눌리지 않는다.
- **운영자 리스트·엑셀** — 팀원이 채운 답이 팀원별로 함께 나온다.

## 데이터

팀원이 채우는 질문은 `assign.consent.questions`에 있다. 작성 화면에서는 폼 상태의
`consent.questions`로 보관하고, 발행할 때 `assign.consent.questions`로 실어 보낸다.

답은 각 팀원의 `values`에 질문 id로 들어간다. **동의 전인 팀원은 비어 있다** — 본인이
동의하며 채우는 값이기 때문이다.

## 못 하는 것

이메일을 팀원이 직접 넣게는 못 한다. 붙박이 필드라 신청폼에만 있다.
필요하면 동의받기 쪽에 `이메일` 주관식 질문을 만들면 된다.

## 이 버전에 없는 것

`event-checkin.html`, `event-fail.html`, `guide.html` 등은 이 변경과 무관해서 옮기지 않았다.
`event-timeslot-0828`의 것을 그대로 본다.
