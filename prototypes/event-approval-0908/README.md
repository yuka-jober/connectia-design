# event-approval-0908 — 운영자 승인 후 확정

`event-timeslot-0907`의 다음 버전. **전원 동의하면 바로 확정되던 것을, 운영자가 승인해야
확정되도록** 바꿨다.

## 왜

자동 배정 자체는 잘 동작했지만 **그 결과를 고칠 수단이 없었다.** 끝자락에 남는 자리,
자리가 차서 실패한 팀, 주최측이 예외로 넣고 싶은 팀 — 전부 막다른 길이 됐다.

자동 배정을 **초안**으로 낮추고 운영자가 확인하는 단계를 넣으면, 자동이 90%를 처리하고
사람이 10%를 다듬는 구조가 된다.

## 상태

```
동의 대기  →  승인 대기  →  확정
                  ↓
             신청 실패 (인원 미달 · 운영자 반려)
```

자리를 차지하는 시점이 상태마다 다르다.

| 상태 | 자리 | 이유 |
|---|---|---|
| 동의 대기 | 안 잡음 | 팀이 성립할지 아직 모른다 |
| 승인 대기 | **잡음** | 잔여 인원이 실제와 맞아야 한다 |
| 확정 | 잡음 | |

승인 대기가 자리를 잡지 않으면, 모집 중 내내 참가자에게 보이는 잔여 인원이 거짓말이 된다.

## 무엇이 바뀌었나

### 이벤트 만들기

자리 배정 블록에 **운영자 승인 후 확정** 토글. 끄면 종전처럼 전원 동의 시 바로 확정된다.

### 참가자

- **신청 화면** — "팀원 전원이 동의하면 주최측 확인 후 자리가 확정돼요" 한 줄 추가
- **동의 현황** — "전원 동의하면 주최측 확인을 거쳐 확정돼요" 한 줄 추가
- **승인 대기 화면** (신규) — 전원 동의 완료 후 확정 전. 확정을 약속하지 않는 문구
- **반려 화면** — 실패 사유에 `운영자 반려` 추가. 재신청해도 같은 결과라 버튼을 감추고 문의로 넘긴다

### 운영자

신청자 리스트에 **승인 대기 N** 버튼. 누르면 대기 건만 남고 선택·일괄 승인 바가 뜬다.

- 자동 배정이 제안한 자리가 `18:00 예정`으로 보이고, 눌러서 바꿀 수 있다
- 전체 선택 → 일괄 승인. 60팀을 하나씩 누르면 못 쓴다
- 반려하면 잡고 있던 자리가 바로 풀린다
- 승인 중에는 참석자·엑셀 버튼을 감춰 줄이 넘치지 않게 했다

## 알림톡

**신규 템플릿 0개.** 승인 대기는 알림톡을 보내지 않고 화면으로만 알린다.

| 시점 | 대상 | 템플릿 |
|---|---|---|
| 팀 신청 직후 | 팀원 전원 | 01 동의 요청 |
| 팀 신청 직후 | 대표자 | 02 현황 안내 · 결과 `동의 대기 중` |
| 전원 동의 완료 | — | **없음** (화면만 바뀜) |
| 운영자 승인 | 팀 전원 | 03 확정 + QR |
| 반려 · 인원 미달 | 대표자 | 02 현황 안내 · 결과 `신청 실패` |

흐름은 [alimtalk-flow.html](alimtalk-flow.html)에 화면과 함께 정리했다.

## 운영

승인은 **모집 중 하루 한 번**을 권한다. 마감 후 몰아서 하면 참가자가 오래 기다리고,
대표자는 동의 완료를 알 방법도 딱히 없다.

## 이 버전에 없는 것

- **인원 단위 정원** — 실서비스에는 들어갔지만 프로토타입은 아직 팀 수 기준이다.
  승인 흐름을 보는 데는 지장이 없다
- `event-checkin.html`은 이 변경과 무관해서 옮기지 않았다
