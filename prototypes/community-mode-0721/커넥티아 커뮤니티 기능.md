# 커뮤니티 모드 (Community Mode)

## 개요
소규모 모임·팀이 자신들의 공간을 함께 운영할 수 있게 하는 **다인(多人) 페이지**. Connectia의 기본 페이지가 한 사람·한 매장을 위한 소개용이라면, 커뮤니티 모드는 **여러 명이 함께 속해 활동하는 페이지**다.

## 목적
- **오프라인 모임의 온라인 홈** — 정기 스터디, 창업자 소모임, 동네 커뮤니티처럼 이미 오프라인에서 만나는 사람들에게 정보가 흩어지지 않는 공용 공간을 제공한다.
- **가벼운 진입** — 카페·디스코드처럼 무거운 세팅 없이, 소개 페이지 하나에 필요한 것들이 붙어 있는 형태.
- **한 명이 운영, 여러 명이 참여** — 운영자가 만들고, 초대받은 사람이 멤버로 들어와 함께 채워간다.

## 제공하는 것
- **소개 화면** — 커뮤니티 이름·설명·대표 이미지. 처음 방문한 사람이 어떤 모임인지 바로 파악할 수 있게.
- **멤버** — 누가 속해 있는지, 어떤 사람들인지.
- **게시글/공지** — 운영에 필요한 소식, 안건 공유 등을 남기는 공간.
- **정기모임·이벤트** — 참석 여부를 받고, 확인 현황을 볼 수 있는 미니 이벤트.
- **초대 → 가입 신청** — 링크로 초대받은 비가입자가 간단한 폼으로 가입 신청, 운영자가 승인.

## 시점 (역할별로 다른 화면)
- **운영자(Owner)** — 모든 것을 편집·승인할 수 있는 시점.
- **멤버(Member)** — 참여·열람 위주. 운영 기능은 감춰진다.
- **비가입자(Guest)** — 초대 링크로 들어온 사람. 소개만 보이고, 가입 신청으로 참여할 수 있다.

## 서비스 원칙과의 연결
- IT에 익숙하지 않은 운영자도 만들 수 있도록 **필드는 최소한**, 화면은 단순하게.
- 온라인 커뮤니티 툴에 익숙하지 않은 멤버도 방문 즉시 무슨 공간인지, 뭘 할 수 있는지 알 수 있어야 한다.
