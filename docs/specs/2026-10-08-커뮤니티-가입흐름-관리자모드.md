# 커뮤니티 가입 흐름 · 관리자 모드 개편

이벤트를 신청한 사람이 모임 회원이 되고 회원 메뉴에 들어가기까지를 하나의 흐름으로 잇는다.
운영자는 회원·방문자에게 보이는 화면을 직접 확인할 수 있게 한다.
2026-10-08 팀 리뷰에서 이대로 진행하기로 확정.

- 팀 공유 페이지 · https://connectia-design.vercel.app/prototypes/join-flow-1008/overview.html
- 프로토타입 1 · 가입 흐름 `review/join-flow.html`
- 프로토타입 2 · 커뮤니티 운영자 `review/community-mode-owner.html`
- 시나리오 영상 · 가입 흐름 8개, 관리자 모드 7개 (11. 파일 목록)

이 문서는 화면 기획과 디자인을 다룬다. 구현 방식은 개발팀이 정한다.

---

## 1. 왜 바꾸나

실서비스 녹화(10/7, 경륜재)에서 사용자가 이벤트 신청 → 가입 신청 → 앱 홈을 오가며 4분 동안 회원 메뉴를 찾지 못했다.

| 영상 시점 | 사용자가 겪은 일 | 문제 |
|---|---|---|
| 0:24 | 신청 완료 화면에 [닫기]만 있음 | 모임 가입으로 이어지는 길이 없다 |
| 0:28 | 방금 신청했는데 "3명 / 신청하기"가 그대로라 한 번 더 신청 | 신청 결과가 화면에 바로 반영되지 않고, 같은 이벤트를 두 번 신청할 수 있다 |
| 1:05 | 가입 폼에 계정 이름이 채워져 있어 고쳐 쓰고, 전화번호도 다시 입력 | 행사 때 쓴 정보가 이어지지 않는다 |
| 1:40 | [신청하기]가 눌리지 않는데 이유를 모름 | 동의 체크박스가 스크롤 아래에 숨어 있다 |
| 1:55 | 회색 [가입 대기중]만 보고 40초 멈춤 | 신청이 끝났는지, 다음에 뭘 해야 하는지 알 수 없다 |
| 2:55 | 새로고침하니 다시 [가입하기] | 가입 대기 상태가 유지되지 않는다 |
| 3:10 | 가입한 커뮤니티에서 경륜재를 못 찾음 | 승인 대기 모임이 목록에 없다 |

운영자 화면에는 관리 기능이 회원 화면과 섞여 있어서, 회원에게 어떻게 보이는지 확인할 방법이 없었다.

---

## 2. 크게 바뀌는 점

1. **가입하지 않은 사람도 회원 메뉴를 본다.** 홈·멤버·게시판·행사 탭이 모두 보이고, 멤버·게시판 내용만 일부 가린다. 가려진 걸 누르면 로그인하지 않았으면 로그인 창, 로그인했지만 회원이 아니면 가입 모달이 뜬다.
2. **이벤트 신청이 곧 가입 입구.** 신청 완료 직후 "회원으로도 가입할까요?" 모달이 뜨고, 행사 때 입력한 이름·전화번호가 가입 폼에 채워진다.
3. **가입 상태가 어디서나 같다.** 이벤트 페이지, 모임 페이지, 가입한 커뮤니티가 같은 상태를 보여주고 새로고침해도 유지된다.
4. **운영자도 기본은 회원 화면.** [관리]를 눌러야 관리자 모드에 들어가고, 관리자 모드에서 방문자 화면도 미리 볼 수 있다.
5. **공개 설정을 하나로 줄인다.** 항목마다 고르던 공개 범위와 멤버가 항목마다 켜던 공개 토글을 없앤다. 연락처만 운영자가 보고, 본인이 원하면 멤버에게 공개한다.
6. **운영자가 미리 등록한 멤버에 '인증 전' 표시.**

## 3. 기본 개념

### 3.1 가입 상태

한 사람이 한 모임에 대해 갖는 상태는 넷 중 하나다.

| 상태 | 언제 |
|---|---|
| 가입 전 | 기본 |
| 승인 대기 | 승인이 필요한 모임에 가입을 신청했을 때 |
| 회원 | 바로 가입되는 모임에 가입했거나, 운영자가 승인했을 때 |
| 거절됨 | 운영자가 거절했을 때 |

- 승인이 필요한지는 모임 설정 "가입 시 운영자 승인 필요"를 따른다(기존 설정).
- 모든 화면이 이 상태 하나를 기준으로 그린다. 화면마다 다르게 보이면 안 된다.

### 3.2 보는 사람

| 보는 사람 | 설명 |
|---|---|
| 비로그인 방문자 | 로그인하지 않음 |
| 방문자 | 로그인했지만 가입 전 또는 거절됨 |
| 승인 대기 | 가입 신청 후 승인을 기다리는 중 |
| 회원 | 가입 완료 |
| 운영자 | 회원 + 운영 권한. 기본은 회원 화면, [관리]로 관리자 모드 |

### 3.3 이벤트 신청

한 사람은 한 이벤트에 한 번만 신청한다. 신청했으면 [신청하기] 대신 [내 신청]이 보인다.

## 4. 가입 흐름 화면

### 4.1 전체 흐름

```
이벤트 랜딩 → [신청하기] → 신청 폼 → [신청 완료]
  → 신청 완료 화면 + 가입 바텀시트
      ① 물어보기  "경륜재 회원으로도 가입할까요?"
         [가입하기] ─→ ② 가입 폼 (이름·전화번호 채워짐) → [가입 신청]
         [다음에 할게요] → 시트만 닫힘
      ③ 결과
         승인제   "가입 신청을 보냈어요" → [내 모임 보기] → 가입한 커뮤니티 '승인 대기'
         즉시 가입 "경륜재 회원이 되었어요" → [회원 메뉴로 가기] → 모임 페이지 + 탭 5개
```

### 4.2 이벤트 랜딩 · 하단 고정 영역

위에서 아래로: 신청자 수 → **모임 상태 행** → [신청하기] 또는 [내 신청] + 문의 아이콘 버튼

**모임 상태 행** — 모임 로고(24px) + 문구 + ›, 연한 회색 면

| 가입 상태 | 문구 | 누르면 |
|---|---|---|
| 가입 전 | 경륜재 가입하기 › | 모임 페이지 |
| 승인 대기 | 경륜재 · 승인 대기 | 모임 페이지 |
| 회원 | 경륜재 회원 메뉴 › | 모임 페이지(회원 메뉴) |
| 거절됨 | 경륜재 다시 신청하기 › | 모임 페이지 |

- 아직 신청하지 않았으면 [신청하기], 신청했으면 [내 신청].
- 신청하자마자 신청자 수와 버튼이 바뀌어 있어야 한다(영상 0:28 문제).

### 4.3 이벤트 신청 폼

- 기존 구성(이름·전화번호·이벤트 질문)은 그대로.
- **개인정보 동의 체크박스는 하단 고정 영역의 [신청 완료] 버튼 바로 위.** 스크롤해도 늘 보인다.
- 버튼은 비활성으로 두지 않는다. 동의하지 않고 누르면 체크박스가 빨간 테두리로 바뀌고 살짝 흔들리며 아래에 "동의해야 신청할 수 있어요".

### 4.4 신청 완료 화면

- 체크 아이콘 + "신청이 완료되었어요" + 일시
- 신청 내용 요약 카드(이름·전화번호·선택한 일정)
- 모임 상태 행(4.2와 같은 규칙)
- 하단 [확인]. 회원이면 [회원 메뉴로 가기]가 함께 보인다.

**가입 바텀시트가 자동으로 뜨는 조건**

| 가입 상태 | 신청 완료 화면에서 |
|---|---|
| 가입 전 | 바텀시트가 자동으로 올라옴 |
| 승인 대기 | 바텀시트 없음. "경륜재 · 승인 대기" 행만 |
| 회원 | 바텀시트 없음. 하단에 [회원 메뉴로 가기] |
| 거절됨 | 바텀시트 없음. "경륜재 다시 신청하기 ›" 행 |
| 모임이 가입을 받지 않음 | 바텀시트 없음 |

### 4.5 가입 바텀시트

시트 한 장이 ① → ② → ③으로 바뀐다. ①에서 ②로 갈 때 시트 높이가 부드럽게 늘어난다.

**① 물어보기**
- 모임 로고(56px) + 제목 + [가입하기](보라 채움) + [다음에 할게요](회색 약한 버튼)
- 제목은 어디서 열었는지에 따라 한 글자 다르다.
  - 이벤트 신청 직후: "경륜재 회원**으로도** 가입할까요?"
  - 모임 페이지·멤버 탭에서: "경륜재 회원**으로** 가입할까요?"
- [다음에 할게요]는 시트만 닫는다. 나중에 이벤트·모임 페이지에 다시 오면 가입 진입점이 그대로 보인다.

**② 가입 폼**
- 상단: 모임 로고 + "경륜재 가입 신청" + 닫기(X)
- 항목: 운영자가 설정한 가입 항목 그대로. **모임마다 폼 모양을 다르게 하지 않는다.** 항목이 이미 다 채워져 있어도 같은 폼을 보여주고, 사용자는 확인만 하고 누르면 된다.
- 미리 채우는 값

  | 항목 | 채우는 값 |
  |---|---|
  | 이름 | 이벤트 신청 때 입력한 이름 (계정 이름보다 우선) |
  | 전화번호 | 이벤트 신청 때 입력한 번호 |
  | 이메일 | 계정 이메일 |
  | 나머지 | 비움 |

  이벤트를 거치지 않고 모임 페이지에서 열었으면 계정 정보로 채우고, 없으면 비운다.
- 필수가 아닌 항목(한 줄 소개·소속·부서 등)은 "선택 항목" 한 줄로 접어 두고, 누르면 펼쳐진다.
- 하단 고정 영역: 동의 체크박스 "개인정보 수집·이용에 동의합니다." → 그 아래 버튼
- 버튼 이름: 승인이 필요한 모임 "가입 신청" / 바로 가입되는 모임 "가입하기"
- 확인: 필수 항목이 비면 토스트 "필수 항목을 채워주세요", 동의하지 않았으면 체크박스 에러 + "동의해야 가입할 수 있어요"

**③ 결과**

| 모임 | 아이콘 | 제목 | 본문 | 버튼 |
|---|---|---|---|---|
| 승인 필요 | 시계 | 가입 신청을 보냈어요 | 운영자 승인 후 회원 메뉴를 이용할 수 있어요.<br>승인되면 알림으로 알려드려요. | [내 모임 보기] / [닫기] |
| 바로 가입 | 체크 | 경륜재 회원이 되었어요 | 없음 | [회원 메뉴로 가기] / [닫기] |

- [내 모임 보기] → 내 페이지 시트가 **가입한 커뮤니티 탭이 열린 채로** 올라온다.
- [회원 메뉴로 가기] → 모임 페이지(회원) + 하단 탭 5개.
- 본문이 알림을 약속하므로, 승인·거절되면 실제로 알림이 가야 한다.

### 4.6 모임 페이지 (가입 전·승인 대기·거절)

실서비스 가입 화면 모양을 그대로 따른다.

```
┌──────────────────────────┐
│ (로고) 경륜재에 초대받았어요│  ← 초대 띠 (연보라 면)
│ [        가입하기        ]│     검정 버튼, 꽉 찬 너비
├──────────────────────────┤
│   [커버 이미지, 아래 페이드] │  ← 좌우 안쪽 여백
│         ( 로고 )          │  ← 가운데, 흰 테두리
│          경륜재           │
│          @krj            │
│         [ 🔗 공유 ]       │
│ [       💬 대화하기       ]│  ← 대화하기 색 프리셋
│ 소개 본문                 │
│ 다가오는 모임             │
│ [카드][카드] →            │  ← 2열, 가로 스크롤
├──────────────────────────┤
│  홈   멤버   게시판   행사  │  ← 탭 4개
└──────────────────────────┘
```

- **초대 띠**: 연보라 면 + 원형 모임 로고(32px) + "**경륜재**에 초대받았어요"(모임 이름만 보라색) + 상태별 버튼
  - 가입 전: [가입하기] (검정 채움, 꽉 찬 너비)
  - 승인 대기: 시계 아이콘 + "승인 대기" 상태 표시. 눌리지 않는 회색 버튼처럼 보이지 않게, 흰 면 위 글자로.
  - 거절됨: [다시 신청하기] (검정 채움)
  - 띠는 홈뿐 아니라 멤버·게시판·행사 탭 맨 위에도 똑같이 붙는다.
- **배경**: 페이지 배경 프리셋(예시는 민트).
- **다가오는 모임 카드**: 흰 카드, 위쪽은 같은 이미지를 흐리게 깐 배경 위에 포스터가 잘리지 않게 놓인다. 아래 흰 영역에 제목(굵게, 자연 줄바꿈)과 설명(회색, 2줄 말줄임). 누르면 이벤트 랜딩.
- **회원이 되면** 초대 띠가 사라지고, 상단에 커뮤니티 이름 바, 하단에 탭 5개(설정 추가).

### 4.7 탭별로 보이는 범위

| 탭 | 방문자 (로그인 전·후) | 승인 대기 | 회원 |
|---|---|---|---|
| 탭바 | 홈·멤버·게시판·행사 | 같음 | + 설정 |
| 홈 | 모임 페이지 | 모임 페이지 | 모임 페이지 |
| 멤버 | 가린 목록, 검색 없음 | 가린 목록 | 전체 목록 + 검색 |
| 게시판 | 제목만 보이고 나머지 흐림. 글쓰기 없음 | 같음 | 전부 (권한에 따라 글쓰기) |
| 행사 | 그대로 보이고 신청 가능 | 그대로 | 그대로 |

**가려진 내용을 누르면**

| 보는 사람 | 동작 |
|---|---|
| 비로그인 | 로그인 창 → 로그인하면 보던 화면으로 돌아와 가입 바텀시트 ① |
| 방문자 | 가입 바텀시트 ① |
| 승인 대기 | 토스트 "승인되면 볼 수 있어요" |

**가리는 방법**
- 멤버 탭 제목은 실제 인원 "멤버 24".
- 이름: 첫 글자와 끝 글자만 남기고 가운데를 \*로 (김서연 → 김\*연, 김파운더 → 김\*\*더). 두 글자 이름은 끝 글자를 \*로 (이호 → 이\*).
- 흐리게: 프로필 사진, 이름 아래 소속·직함 줄, 게시글 작성자 줄·본문·댓글 수. 흐림 정도는 모두 같게(`--blur-dim`의 두 배, 4px). 읽을 수는 없지만 무언가 있다는 건 보이는 정도.
- 게시판은 제목과 '공지' 표시만 또렷하게.
- 흐린 내용도 실제 이름·내용이 아니어도 된다(화면상 자리만 채우면 됨). 개인정보가 노출되지 않게 개발팀과 확인.

### 4.8 내 페이지 › 가입한 커뮤니티

- 승인 대기 모임도 목록에 나온다.
- 모임 이름 아래 상태 글자: "승인 대기"(진한 회색, 약간 굵게) / "가입 완료"(연한 회색). 뱃지 대신 글자 크기·색으로 구분.
- 거절된 모임은 목록에 없다.
- 누르면 그 모임 페이지.

## 5. 커뮤니티 운영자 화면

### 5.1 세 가지 화면 모드

| 모드 | 들어가는 법 | 상단 바 |
|---|---|---|
| 회원 화면 (기본) | 처음 들어왔을 때 | 흰 바: 커뮤니티 이름 ▾ + **[관리]** + 내 아바타. [관리]는 운영자에게만 보임 |
| 관리자 모드 | [관리] | **검정 바**: "관리자 모드" + [방문자로 보기](흰 테두리 버튼, 눈 아이콘) + [완료](흰 버튼) |
| 방문자 화면 미리보기 | 관리자 모드의 [방문자로 보기] | 검정 바: "방문자 화면" + [닫기] → 관리자 모드로 돌아감 |

- 세 모드 모두 상단 바 높이가 같다. 바꿀 때 화면이 위아래로 튀지 않고 바 색만 바뀐다.
- 모드를 바꿀 때 토스트는 띄우지 않는다. 바 색이 바뀌는 것으로 충분하다.
- 관리 전용 화면(초대 관리, 멤버 정보 설정 등)을 보다가 [완료]를 누르면 그 탭의 첫 화면으로 간다. 열려 있던 관리용 시트는 닫힌다.
- 방문자 화면 미리보기는 4.6·4.7과 똑같이 보인다(초대 띠, 탭 4개, 가린 목록). 미리보기라서 [가입하기]나 멤버를 눌러도 아무 일도 일어나지 않는다.

### 5.2 회원 화면에서는 안 보이는 것

| 위치 | 관리자 모드에서만 보임 |
|---|---|
| 멤버 탭 | 멤버 정보 설정 아이콘, 멤버 추가(+), "가입 대기 N명" 줄, 칩 이름 바꾸기·삭제, 칩 추가(+) |
| 멤버 상세 | 더보기(편집·내보내기), 권한 바꾸기(회원 화면에선 글자로만), "로그인하면 자동 연결", 미가입 멤버 전화번호 |
| 게시판 | [글쓰기] — 단, 글쓰기 권한이 '일반 멤버 이상'이나 '누구나'면 회원 화면에도 보인다 |
| 행사 | [만들기], 행사 상세의 '확인 현황' |
| 설정 | 소유자 뱃지, [통계]·[모임 설정], 멤버 관리·초대 관리·멤버 정보, 글쓰기·댓글 권한, 커뮤니티 삭제 |

회원 화면의 설정 탭에는 **내 프로필 카드와 "모임 나가기"만** 남는다.

### 5.3 멤버 정보 설정 (운영자 › 설정 › 멤버 정보)

- 항목 설정 시트에서 "보여주기(프로필에서만 / 운영자만)"를 **없앤다.** 시트에는 "가입할 때 받기", "필수 여부", (고르기 항목이면) "선택지"만 남는다.
- **전화번호·이메일은 연락처로 보고, 처음부터 운영자만 본다.** 따로 설정하지 않는다.
- 그 밖의 항목은 모두 멤버끼리 보인다.
- 목록 표시(눈 아이콘, 최대 2개)는 그대로. 연락처 항목은 눈 아이콘이 꺼진 채 고정.

### 5.4 이 모임에서 내 프로필 (회원)

- 항목마다 있던 [공개] 토글을 **없앤다.**
- 섹션 제목 "멤버에게 공개할 정보" → **"내 정보"**
- 섹션 맨 아래 토글 하나: **"연락처를 멤버에게 공개"** (기본 꺼짐)
- 보여주기 싫은 선택 항목은 비우면 된다.

### 5.5 멤버 상세에서 보이는 범위

| 항목 | 회원이 볼 때 | 운영자(관리자 모드) |
|---|---|---|
| 연락처가 아닌 항목 | 전부 | 전부 |
| 전화번호·이메일 | 그 멤버가 "연락처를 멤버에게 공개"를 켰을 때만 | 항상 |

### 5.6 '인증 전' 뱃지

- 운영자가 명단으로 미리 등록했고, 아직 본인이 가입·인증하지 않은 멤버.
- 멤버 목록의 이름 옆, 멤버 상세의 "상태" 줄에 회색 뱃지 "인증 전"(작은 크기, 무채색).
- 회원·운영자 모두에게 보인다. 관리자 모드에서는 상세에 "로그인하면 자동 연결" 토글과 전화번호도 보인다.
- (기존 "가입 전" 회색 글자를 대체)

### 5.7 모임 나가기

설정 › "모임 나가기"(빨간 글자) → 확인창 "모임에서 나갈까요?" [취소] / [나가기](빨간 채움) → 토스트 "모임에서 나갔어요" → 가입 전 상태가 된다.

## 10. 디자인 기준

- 색·글자·간격은 `tokens.css`, 컴포넌트는 `components.css`만 쓴다. 이번 작업에서 두 파일은 바꾸지 않았다.
- 무채색 위주. 상태는 뱃지보다 글자 크기·색으로 구분한다('인증 전'만 예외로 뱃지).
- 주요 요소별 컴포넌트

  | 요소 | 사용 |
  |---|---|
  | 가입 바텀시트 | 바텀시트 + 큰 버튼(보라 채움 / 회색 약한) |
  | 초대 띠 버튼 | 큰 버튼, 검정 채움, 꽉 찬 너비 |
  | 관리자 모드 상단 바 | 어두운 면 + 작은 알약 버튼(흰 채움 / 흰 테두리) |
  | [관리] | 작은 알약 버튼, 회색 약한 |
  | 인증 전 | 작은 뱃지, 회색 약한 |
  | 연락처 공개 | 토글 |
  | 모임 나가기 확인 | 다이얼로그 + 빨간 채움 버튼 |

- 공용으로 만들면 좋을 것(지금은 각 프로토타입 안에만 있음)
  - 모임 상태 행 (로고 + 문구 + ›)
  - 하단 고정 동의 체크박스 + 에러 상태
  - 버튼 자리에 놓는 상태 표시 (시계 + 승인 대기)
  - 초대 띠
  - 가린 멤버 행 (마스킹 이름 + 흐림)
  - 커뮤니티 상단 바·하단 탭바
