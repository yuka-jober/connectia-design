# 통계 화면 개선 PRD

> 디자인 토큰·구현 코드는 별도 시스템에서 처리한다. 이 문서는 **화면을 어떻게 구성할지(섹션, 순서, 표시 내용, 상태 처리)** 만 지시한다.
>
> **핵심 방향**: (1) 최대한 단순하게, (2) 사장님이 **답변 못한 질문에 답(자료)을 채우게 만드는 것**을 화면의 1차 목적으로 둔다. 통계 열람은 부차적.

---

## 1. 개요

- **대상 화면**: AI 페이지 통계 화면 (단독 화면으로 구성)
- **사용자**: IT에 익숙하지 않은 소상공인
- **1차 목표**: 사장님이 **답변 못한 질문에 답을 채우도록** 유도한다. 숫자를 구경하는 화면이 아니라, 할 일을 하게 만드는 화면.
- **범위 제외**: 상위 탭 구조(통계/자료/정체성/대화)는 이번 화면 범위에서 다루지 않는다.

---

## 2. 전역 동작 — 기간 선택기

- 화면 **최상단**에 세그먼트: `오늘` / `이번 주` / `이번 달`. 기본값 `오늘`.
- 단어는 '일간/주간/월간', '최근 7일/30일' 대신 `오늘 / 이번 주 / 이번 달` 사용.
- **선택한 기간이 화면 전체 숫자에 일괄 적용된다** (데이터 정합성 — 서로 다른 기간의 숫자가 한 화면에 섞이지 않게).
- **추세 그래프는 넣지 않는다.** 모든 지표는 **큰 숫자 + 한 줄 텍스트 증감**("지난주보다 +8")으로만 표현한다.
  - 이유: 저볼륨 가게에선 그래프가 노이즈라 단순 숫자가 더 잘 읽힌다. 그래프는 데이터가 쌓인 뒤 추후 재검토.

---

## 3. 섹션 구성 및 순서

> 위 → 아래 순서가 곧 중요도다.

### 3.1 채워야 할 질문 (최상단 / 화면의 주인공)

기존 '답변하지 못한 질문'을 화면 맨 위 히어로 블록으로 올린다.

- **정렬**: 많이 물어본 순. 각 질문에 횟수를 함께 표시한다 (예: "이건 5번 물어봤어요"). 효과 큰 것부터 채우게 한다.
- **문구는 실패가 아니라 기회로**: 헤드라인 예 — "이 N개만 채우면 AI가 답할 수 있어요". '답변하지 못한' 같은 혼나는 표현은 피한다.
- **한 번에 한 동작**: 질문을 누르면 바로 그 질문의 **답 입력 화면**으로 이동한다. 가능하면 질문은 미리 채워두고 사장님은 답만 쓰게 한다.
- **한꺼번에 쏟지 않는다**: 상위 몇 개만 노출하고 나머지는 `더보기`.
- **보조 지표(작게)**: 답변율(%)을 이 블록 안에 작은 한 줄로 둔다. 낮으면 경고 상태로 표시. (히어로는 어디까지나 '채울 질문 목록'이고, 답변율은 옆에 붙는 건강 신호.)
- **빈 상태(채울 게 없을 때)**: "지금은 AI가 다 답하고 있어요" 같은 긍정 안내로 받아준다.

### 3.2 핵심 지표

- 카드 2개: `받은 대화` / `페이지를 본 사람`(= 기존 프로필 조회수, 쉬운 말로 변경).
- 각 숫자 아래에 한 줄 증감(직전 동일 기간 대비). 그래프 없음.
  - `이번 주` 예: "지난주보다 +8" / `오늘` 예: "어제 이맘때보다 +1".

### 3.3 자주 묻는 질문 *(단순화가 더 중요하면 생략 가능)*

- 선택 기간 기준, 많이 물어본 순, 질문 전문 표시(말줄임 최소화) + 횟수.
- 3.1은 'AI가 답 못 한' 질문, 3.3은 'AI가 답하고 있는' 질문 — 성격이 다르다.
- 화면을 더 가볍게 가고 싶으면 이 섹션은 빼도 무방하다.

### 3.4 최근 대화

- 각 항목: **사용자 이름 + 질문 요약 + 상대 시간**.
- 이름 표기: 비로그인 사용자 → `익명의 사용자` / 로그인 사용자 → 실제 이름.
- 제목은 'Shared Chat' 같은 고정 문구 대신 그 대화의 실제 질문 요지로.

### 3.5 정보를 제출한 사람

- 데이터가 있으면 목록을 보여준다.
- **빈 상태**: 단순 "없습니다"가 아니라 행동 유도 문구로 — 예: "이벤트를 열어 고객 정보를 모아보세요".

---

## 4. 공통 규칙

- **라벨 통일**: 모든 '더보기 / 전체 보기' 류를 `더보기` 하나로 통일.
- **0 / 빈 상태 처리**: 숫자 0이 고장처럼 보이지 않게 부드러운 안내 — 예: "오늘은 아직 받은 대화가 없어요".
- **데이터 정합성**: 모든 숫자는 상단 기간 선택기와 동일한 기간 기준.
- **위계**: `채워야 할 질문 → 핵심 지표 → (자주 묻는 질문) → 최근 대화 → 정보를 제출한 사람` 순서를 유지한다.
- **단순함 우선**: 새 요소를 더하기 전에, 위 1차 목표(자료 채우기)에 도움이 되는지 먼저 따진다.
