# 새 페이지 만들기 — 프리셋으로 시작하기

**파일** `avatar-create.html` · **2026-10-16**

---

## 무엇을 바꾸나

지금은 용도를 여섯 개(이력서 · 세일즈 · 서비스 소개서 · 프로필 페이지 · CS · 명함) 중에
고르고, 다음 화면에서 예시를 본 뒤 "이 템플릿으로 만들기"를 누른다.

두 가지가 걸린다.

- **용도 이름의 성격이 섞여 있다.** 이력서·서비스 소개서는 문서, 세일즈·CS는 업무,
  명함·프로필 페이지는 페이지 형태다. 무엇을 고르는 자리인지 흐려진다.
- **고른 것이 페이지 구조와 이어지지 않는다.** 편집이 블록형으로 바뀌면서 프로필 머리
  레이아웃과 카드 면을 고를 수 있게 됐는데, 시작 화면은 그것을 모른다.

블록형은 자유도가 높은 대신 **빈 캔버스에서 혼자 쌓아야 하는 부담**이 생긴다. 시작 화면이
그 부담을 덜어야 한다 — 고르면 **블록이 이미 올라가 있고 설정도 잡혀 있는** 상태로 들어간다.

---

## 프리셋 네 가지

페이지 형태로만 가른다.

| | 프로필 레이아웃 | 카드 면 | 미리 올라가는 블록 |
|---|---|---|---|
| **명함** | 명함 | 있음 | SNS · 소개 · 링크 목록 |
| **프로필 1** | 원형 | 없음 | 소개 · 갤러리 · 링크 목록 · 리뷰 |
| **프로필 2** | 큰 이미지 | 있음 | 소개 · 갤러리 · 링크 목록 |
| **모임** | 큰 이미지 | 있음 | 소개 · 이벤트 · 게시판 · 링크 목록 |

- **명함**은 연락처가 카드 안에 들어가므로 블록으로 따로 서지 않는다.
- **프로필 1·2**는 머리가 다르다 — 사람을 앞세우면 원형 사진, 작업이나 공간을 앞세우면
  큰 이미지다. 둘 다 사진과 받은 평이 중심이다.
- **모임**은 앞으로 할 일이 중심이라 이벤트가 위에 온다.

고른 것은 나중에 전부 바꿀 수 있다. 프리셋은 **출발점이지 틀이 아니다.**

카드를 누르면 **그 블록이 선 빈 편집 화면**으로 들어간다. 블록만 서 있고 이름·사진·내용은
비어 있다 — 무엇을 채워야 하는지가 화면에 그대로 보인다.

---

## 화면

한 화면에서 끝낸다. 고르기 → 미리보기 → 만들기로 나누지 않는다.

- 카드마다 **그 프리셋이 만들어 낼 페이지를 줄여 그린다.** 커버가 어디까지 보이는지,
  머리가 명함인지 원형인지, 어떤 섹션이 어떤 차례로 서는지가 그림으로 읽힌다.
- 손으로 그린 축소판이 아니라 **실제 페이지를 찍은 그림**을 쓴다. 프리셋마다 예시 페이지를
  만들어 두고(`example.html`) 그것을 찍는다 — 명함은 튼튼내과, 프로필 1은 글로스네일,
  프로필 2는 하루요가, 모임은 서울시립대학교 총동문회. 약속한 것과 만들어지는 것이 같다.
- 넓은 화면에서는 **가리킨 한 장이 커지고 나머지가 물러난다.** 좁은 화면에서는 네 장을
  세로로 쌓지 않고 **가운데 한 장이 서고 양옆이 겹쳐 물러난다** — 밀어 가며 견주는 자리이기
  때문이다. 옆에 있던 장을 누르면 먼저 가운데로 온다. 반쯤 가린 장이 바로 만들어지면 곤란하다.
- **무엇이 들어가는지 글로 적지 않는다.** 미리보기가 그 일을 한다.
- 고르는 단계와 확정하는 단계를 나누지 않는다. **카드를 누르면 그대로 만들어진다** — 고른 것은
  편집 화면에서 전부 바꿀 수 있으니, 되돌릴 수 없는 선택이 아니다.
