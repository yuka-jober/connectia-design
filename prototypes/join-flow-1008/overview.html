커뮤니티 가입 흐름 개편

이벤트를 신청한 사람이 모임 회원이 되고, 회원 메뉴에 들어가기까지를 하나의 흐름으로 이었어요. 운영자가 회원·방문자에게 보이는 화면을 직접 확인할 수 있는 관리자 모드도 함께 정리했어요.

작성 2026.10.08상태 팀 리뷰 대기예시 모임 경륜재 · 서울 파운더스 테이블
크게 바뀌는 점왜 바꾸나누가 무엇을 보나가입 흐름 시나리오관리자 모드 시나리오개발 전달

크게 바뀌는 점

  1. 가입하지 않은 사람도 회원 메뉴를 봐요

    홈·멤버·게시판·행사 탭이 모두 보이고, 멤버·게시판 내용만 일부 가려져요. 가려진 걸 누르면 로그인하지 않았으면 로그인 창, 로그인했지만 회원이 아니면 가입 모달이 떠요.

  2. 이벤트 신청이 곧 가입 입구예요

    신청 완료 직후 "회원으로도 가입할까요?" 모달이 뜨고, 행사 때 입력한 이름·전화번호가 가입 폼에 채워져요.

  3. 가입 상태가 어디서나 같아요

    가입 전 / 승인 대기 / 회원 / 거절을 이벤트 페이지, 모임 페이지, 가입한 커뮤니티가 똑같이 보여줘요. 새로고침해도 유지돼요.

  4. 운영자도 기본은 회원 화면이에요

    [관리]를 눌러야 관리자 모드로 들어가요. 관리자 모드에서 [방문자로 보기]로 가입 전 사람의 화면도 확인할 수 있어요.

  5. 공개 설정이 하나로 줄었어요

    항목마다 고르던 공개 범위와 멤버별 항목 토글을 없앴어요. 연락처(전화·이메일)만 운영자가 보고, 본인이 공개를 켜면 멤버에게도 보여요.

  6. 운영자가 등록한 멤버는 '인증 전' 표시

    명단으로 미리 등록하고 아직 본인 인증을 하지 않은 멤버에게 뱃지가 붙어요.

  7. 회원만 신청할 수 있는 행사

    '회원 전용' 행사에서 회원이 아닌 사람이 [신청하기]를 누르면 "회원만 신청할 수 있어요 · 경륜재에 가입할까요?"가 떠요. 바로 가입되는 모임이면 [이어서 신청하기]로 신청까지 이어져요.

왜 바꾸나

실서비스 녹화(10/7)에서 사용자가 이벤트 신청 → 가입 신청 → 앱 홈을 오가며 4분 동안 회원 메뉴를 찾지 못했어요.

신청 완료 화면에 [닫기]만 있고 모임 가입으로 이어지지 않음

신청 완료 직후 "회원으로도 가입할까요?" 모달

행사 때 쓴 이름·전화번호를 가입 신청에서 다시 입력

가입 폼에 자동으로 채워짐

'가입 대기중'만 보이고 다음 행동이 없어 40초 정지

결과 안내 + [내 모임 보기] / [회원 메뉴로 가기]

가입한 커뮤니티에 대기 중 모임이 없고, 재방문하면 상태가 사라짐

모든 화면이 같은 가입 상태를 보여줌

운영자 화면에 관리 요소가 섞여 회원이 보는 화면을 알 수 없음

[관리]로 들어가는 관리자 모드 + 방문자 화면 미리보기

비회원은 모임 안에 뭐가 있는지 볼 수 없음

탭은 모두 보이고 멤버·게시판 내용만 가림 → 누르면 가입 모달

누가 무엇을 보나

화면 구조는 하나예요. 보는 사람에 따라 얼마나 보이는지만 달라져요.

프로토타입 1 · join-flow

가입 흐름 시나리오

예시: 모임 '경륜재', 이벤트 '10월 경륜재 정기 모임'. 영상마다 첫 2초는 시나리오 제목이에요.

01

기본 경로 · 승인제 모임

  1. 이벤트 [신청하기] → 이름·전화번호·일정 → [신청 완료]
  2. "경륜재 회원으로도 가입할까요?" → [가입하기]
  3. 가입 폼에 이름·전화번호가 채워져 있음, 이메일은 계정값
  4. 동의 없이 누르면 체크박스에 에러 → 동의 → [가입 신청]
  5. "운영자 승인 후 회원 메뉴를 이용할 수 있어요" → [내 모임 보기]
  6. 가입한 커뮤니티에 '승인 대기' → 새로고침해도 유지
02

기본 경로 · 즉시 가입 모임

  1. 이벤트 신청 → 가입 모달 → [가입하기]
  2. 동의 → [가입하기]
  3. "경륜재 회원이 되었어요" → [회원 메뉴로 가기]
  4. 하단 탭바 5개(설정 포함)로 바로 이동
03

다음에 할게요 → 다시 방문

  1. 가입 모달에서 [다음에 할게요] → 모달만 닫힘
  2. 이벤트 재방문: [내 신청] + "경륜재 가입하기 ›"
  3. 모임 페이지 상단 [가입하기] → 가입 → 승인 대기
04

이미 회원인 사람

  1. 이벤트 신청 → 가입 모달 없음
  2. 완료 화면의 [회원 메뉴로 가기]
05

이미 승인 대기 중인 사람

  1. 이벤트 신청 → 가입 모달 없음
  2. 완료 화면에 "경륜재 · 승인 대기" 행 → 모임 페이지
06

이미 신청한 이벤트 재방문

  1. [신청하기] 대신 [내 신청] → 중복 신청 방지
  2. 신청 내용 확인
07

가입이 거절된 사람

  1. 모임 페이지 상단 [다시 신청하기]
  2. 가입 폼 → 승인 대기 → [내 모임 보기]
08

방문자가 멤버 탭을 보고 가입

  1. 가입 전에도 탭바 4개(홈·멤버·게시판·행사)
  2. 멤버 탭: 김*연처럼 가려진 목록 → 누르면 가입 모달
  3. 가입 신청 후 다시 누르면 "승인되면 볼 수 있어요"
  4. 게시판: 제목만 보이고 본문은 흐림

영상은 로그인한 방문자 기준이에요. 로그인하지 않았으면 가입 모달 대신 로그인 창이 먼저 떠요.

09

회원 전용 행사 · 승인이 필요한 모임

  1. '회원 전용' 뱃지가 붙은 이벤트 → [신청하기]
  2. "회원만 신청할 수 있어요" · 경륜재에 가입할까요? → [가입하기]
  3. 가입 폼 → 동의 → [가입 신청] → 승인 대기
  4. 다시 [신청하기] → "승인되면 신청할 수 있어요"
10

회원 전용 행사 · 바로 가입되는 모임

  1. [신청하기] → "회원만 신청할 수 있어요" → [가입하기]
  2. "경륜재 회원이 되었어요" → [이어서 신청하기]
  3. 신청 폼에 이름·전화번호가 채워져 있음 → [신청 완료]
  4. 이미 회원이라 가입 모달 없이 신청 완료
프로토타입 2 · 커뮤니티 운영자

관리자 모드 시나리오

운영자도 기본은 회원 화면이에요. 상단 [관리]를 누르면 상단 바가 어두워지며 관리자 모드로 들어가고, [완료]로 나와요.

01

회원 화면 ↔ 관리자 모드

  1. 회원 화면 멤버 탭: 검색·목록만
  2. [관리] → 멤버 추가·가입 대기 2명·칩 편집이 나타남
  3. 설정 탭: 관리 메뉴와 권한 → [완료]로 복귀
02

글쓰기 권한이 회원 화면에 반영

  1. 관리자 모드 › 설정 › 글쓰기 권한 '관리자만'
  2. [완료] → 회원 화면 게시판에 [글쓰기] 없음
  3. '일반 멤버 이상'으로 되돌리면 다시 보임
03

연락처는 공개한 사람만

  1. 회원 화면: 박서연(비공개) 상세에 이메일 없음
  2. 이준호(공개) 상세에는 이메일 있음
  3. 관리자 모드에선 박서연도 전부 보임
04

내 연락처 공개하기

  1. 설정 › 이 모임에서 내 프로필
  2. "연락처를 멤버에게 공개" 토글 켜기 (기본 꺼짐)
  3. 내 멤버 상세에 이메일이 나타남
05

운영자가 등록한 인증 전 멤버

  1. 목록과 상세에 '인증 전' 뱃지
  2. 관리자 모드: 로그인하면 자동 연결, 전화번호까지
  3. 회원 화면: 뱃지와 기본 정보만
06

방문자 화면 미리보기

  1. 관리자 모드 › [방문자로 보기]
  2. 초대 띠 + 탭 4개, 멤버 이름 가림, 게시글 본문 흐림
  3. [닫기]로 관리자 모드 복귀
07

모임 나가기

  1. 회원 화면 설정: 내 프로필 + 모임 나가기만
  2. "모임에서 나갈까요?" → [나가기]

개발 전달

프로토타입은 아래 버그가 고쳐졌다는 전제로 동작해요.

먼저 고쳐야 할 버그

  • 새로고침하면 '가입 대기' 상태가 사라지고 [가입하기]로 돌아감
  • 신청 직후 이벤트 페이지가 갱신되지 않아 같은 이벤트가 2번 신청됨 (서버에서도 중복 차단 필요)
  • 가입한 커뮤니티에 승인 대기 모임이 안 보임

구현에 필요한 것

  • 계정×모임마다 가입 상태 하나: 가입 전 / 승인 대기 / 회원 / 거절. 모든 화면이 이 값을 읽음
  • 가입 모달은 '가입 전'일 때만 자동 노출
  • 이벤트 입력값(이름·전화번호)을 계정 이름보다 우선해 프리필
  • 승인·거절 시 알림 발송
  • 연락처(전화·이메일)는 운영자 고정 + 본인 공개 토글
