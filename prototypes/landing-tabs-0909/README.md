# landing-tabs-0909 — 유형별 안내 탭을 폴더 모양으로

`event-approval-0908`의 이벤트 랜딩만 떼어낸 파일. **상태 전환 바가 없다** — 열면 바로
참가자가 보는 화면이다.

## 바뀐 것

유형별 안내 탭(졸업생 / 재학생 팀)을 **밑줄 탭에서 폴더 탭으로** 바꿨다.

```
전 ─ 졸업생  재학생 팀        탭이 본문과 따로 놀았다
     ─────
     후배들에게 …

후 ─ ┌─────┐
     │졸업생│ 재학생 팀        고른 탭이 본문과 이어진다
   ┌─┘     └──────────┐
   │ 후배들에게 …       │
   └──────────────────┘
```

- 고른 탭은 흰 배경으로 본문 카드와 이어지고, 나머지는 회색으로 뒤에 물러난다
- 탭과 본문을 `.ptype-folder`로 감쌌다. 부모의 `gap` 때문에 둘이 16px 떨어져서 폴더로 안 붙었다
- 고른 탭에 `transform: translateY(1px)` — 본문 카드의 윗선을 덮어 이어 붙인다

## 손대지 않은 것

운영자 신청자 리스트의 유형 필터는 같은 밑줄 탭 클래스(`.ptype-tab-line`)를 쓰고 있었다.
그건 그대로 두고 랜딩 안내 탭만 `.ptype-folder-tab`으로 따로 뺐다.
