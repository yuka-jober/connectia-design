# screens-approval-0908 — 승인 대기 · 신청 실패

운영자 승인 단계에서 **새로 필요한 두 화면만** 따로 뺀 폴더. 각 파일은 혼자 열린다.
전체 흐름은 [event-approval-0908](../event-approval-0908/)에 있다.

## event-review.html — 승인 대기 (대표자)

전원 동의 완료와 확정 사이에 새로 생긴 구간.

- 상태 뱃지 `승인 대기`, 고른 자리 · 팀원 수 · 동의 완료 시각
- **배정될 자리는 보여주지 않는다.** `19:00 예정`이라고 했다가 승인 때 바뀌면 그게 컴플레인이 된다
- 문구는 확정을 약속하지 않는 톤으로
- **이 상태에서는 알림톡을 보내지 않는다.** 대표자가 들어왔을 때 이 화면이 유일한 안내다

## event-fail.html — 신청 실패 (대표자)

사유 다섯 가지를 상단 바에서 전환할 수 있다. 주소로도 열린다 — `?reason=rejected`

| 사유 | 성격 | 재신청 버튼 |
|---|---|---|
| 거절 · 미응답 · 시간 초과 · 대표자 제외 | 인원 미달로 팀이 성립 안 됨 | 있음 |
| **운영자 반려** | 팀은 멀쩡한데 주최측이 받지 않음 | **없음** |

반려는 재신청해도 같은 결과라 버튼을 감추고 총동문회 연락처로 문의하게 한다.
연락처는 이벤트 설정에 등록된 값을 가져오는 구조다.
