# applicant-list-0910 — 신청자 리스트 반응형 개편

기획서 · [docs/specs/2026-09-10-신청자-리스트-반응형.md](../../docs/specs/2026-09-10-신청자-리스트-반응형.md)

실서버 화면은 "목록"인데 모든 신청자의 상세를 세로로 이어붙이고 있었다.
그래서 PC에서는 폭을 못 쓰고, 모바일에서는 고정 헤더 7줄에 밀려 내용이 안 보였다.

**한 줄에 한 신청.** 같은 줄이 PC에서는 컬럼으로 늘어서고 모바일에서는 두 층으로 접힌다.
레이아웃을 두 벌 만들지 않는다.

## 보는 법

브라우저 폭을 줄였다 늘였다 하면 768px에서 바뀐다.

| | PC (≥768px) | 모바일 (<768px) |
|---|---|---|
| 모달 | 최대 1280px · 높이 90vh | 화면 전체 |
| 헤더 | 두 줄 (탭·타임 칩이 한 줄에) | 두 줄 (타임 칩은 목록과 함께 스크롤) |
| 목록 줄 | 컬럼 일곱 개 | 이름/상태 · 유형·자리 · 버튼 세 층 |
| 상세 | 두 열 | 한 열 |

줄을 누르면 상세가 펼쳐지고, 체크박스를 고르면 하단에 일괄 처리 바가 뜬다.

## 확인한 것

- 고정 헤더 107px (실서버는 모바일 화면의 대부분)
- 모바일 첫 화면에 신청 6건이 보인다
- 390px에서 가로 넘침 없음
