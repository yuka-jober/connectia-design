# 이벤트 신청 → 모임 가입 흐름 · 시나리오별 경로

프로토타입: `prototypes/join-flow-1008/join-flow.html` · 영상: `videos/01~10` (전체본 `00-all-scenarios.mp4`)
예시: 모임 '경륜재', 이벤트 '10월 경륜재 정기 모임'

## 1. 기본 경로 · 승인제 모임
이벤트 페이지 [신청하기] → 신청 폼(이름·전화번호·참여 일정) → [신청 완료]
→ 신청 완료 화면 위로 "경륜재 회원으로도 가입할까요?" → [가입하기]
→ 가입 폼(이름·전화번호 자동 입력, 이메일은 계정 이메일) → 선택 항목 펼쳐 한 줄 소개 입력
→ 동의 없이 [가입 신청] → 동의 체크박스에 에러 표시 → 동의 체크 → [가입 신청]
→ "가입 신청을 보냈어요 / 운영자 승인 후 회원 메뉴를 이용할 수 있어요. 승인되면 알림으로 알려드려요."
→ [내 모임 보기] → 내 페이지 › 가입한 커뮤니티: 경륜재 '승인 대기'
→ 경륜재 → 모임 페이지 상단 '승인 대기' → 새로고침해도 '승인 대기' 유지
→ 다가오는 모임 카드 → 이벤트 페이지: [내 신청] + "경륜재 · 승인 대기"

## 2. 기본 경로 · 즉시 가입 모임
이벤트 신청 → 신청 완료 + 가입 모달 → [가입하기] → 동의 → [가입하기]
→ "경륜재 회원이 되었어요" → [회원 메뉴로 가기]
→ 모임 페이지 + 하단 탭바(홈/멤버/게시판/행사/설정) → 게시판 → 멤버

## 3. 다음에 할게요 → 다시 방문
이벤트 신청 → 신청 완료 + 가입 모달 → [다음에 할게요] → 모달만 닫힘 → [확인]
→ 새로고침 → 이벤트 페이지: [내 신청] + "경륜재 가입하기 ›"
→ 모임 페이지로 이동 → 상단 [가입하기] → 가입 폼 → 동의 → [가입 신청] → 승인 대기 → [닫기]

## 4. 이미 회원인 사람이 이벤트 신청
이벤트 신청 → 신청 완료 (가입 모달 없음)
→ 하단 [회원 메뉴로 가기] → 회원 메뉴

## 5. 이미 승인 대기인 사람이 이벤트 신청
이벤트 신청 → 신청 완료 (가입 모달 없음)
→ 완료 화면에 "경륜재 · 승인 대기" 행 → 탭하면 모임 페이지(상단 '승인 대기')

## 6. 이미 신청한 이벤트에 다시 방문
이벤트 페이지: [신청하기] 대신 [내 신청] (중복 신청 방지)
→ [내 신청] → 신청 내용 확인 → [확인]

## 7. 가입이 거절된 사람
모임 페이지 상단 [다시 신청하기] → 가입 폼 → 동의 → [가입 신청]
→ 승인 대기 결과 → [내 모임 보기] → 가입한 커뮤니티: 경륜재 '승인 대기'
(이벤트 페이지에는 "경륜재 다시 신청하기 ›" 행)

## 8. 방문자가 멤버 탭을 보고 가입
모임 페이지(가입 전)에도 하단 탭바 4개(홈·멤버·게시판·행사)
→ [멤버] → 김*연처럼 가려진 목록 → 아무 멤버나 누름 → "경륜재 회원으로 가입할까요?" → [가입하기]
→ 가입 폼 → 동의 → [가입 신청] → 승인 대기 → [닫기]
→ 다시 멤버를 누르면 토스트 "승인되면 볼 수 있어요"
→ [게시판] → 제목만 보이고 본문은 흐림
(로그인하지 않았으면 가입 모달 대신 로그인 창이 먼저 떠요)

## 9. 회원 전용 행사 · 승인이 필요한 모임
'회원 전용' 뱃지가 붙은 이벤트 → [신청하기]
→ "회원만 신청할 수 있어요 / 경륜재에 가입할까요?" → [가입하기]
→ 가입 폼 → 동의 → [가입 신청] → "가입 신청을 보냈어요" → [닫기]
→ 다시 [신청하기] → 토스트 "승인되면 신청할 수 있어요"

## 10. 회원 전용 행사 · 바로 가입되는 모임
'회원 전용' 이벤트 → [신청하기] → "회원만 신청할 수 있어요" → [가입하기]
→ 가입 폼 → 동의 → [가입하기] → "경륜재 회원이 되었어요" → [이어서 신청하기]
→ 신청 폼(이름·전화번호 채워짐) → 일정 선택·동의 → [신청 완료]
→ 신청 완료 (이미 회원이라 가입 모달 없음)
