# 프로필 페이지 배너 기능 PRD

> 대상: Claude Code 전달용 / 범위: 기획·구성·흐름 (디자인·순서변경 제외)

## 1. 개요

프로필 페이지에 특정 게시글을 강조 노출하는 **배너** 기능을 추가한다.
배너는 새로운 콘텐츠 타입이 아니라, **기존 게시판 게시글 중 일부를 수동으로 "고정"하여 프로필 배너 영역에 노출하는 표현 레이어**다.
진행 중인 이벤트·프로모션·공지 등 방문자에게 먼저 보여주고 싶은 글을 상단에서 강조하는 것이 목적이다.

참고 패턴: 카카오톡 채널 "상단 고정", 네이버 스마트플레이스 "소식".

## 2. 핵심 개념

- 배너 = "배너 노출"로 지정된 게시판 게시글.
- 별도의 배너 데이터/작성 플로우를 만들지 않는다. 게시글에 "배너 노출 여부" 플래그만 추가한다.
- 배너 탭 시 연결된 게시글 상세로 이동한다. (게시글 목록에서 같은 글을 탭한 것과 동일한 동작·도착지)
- 연결 가능한 글은 이벤트 타입에 한정하지 않고 **작성자의 게시글 전체**를 대상으로 한다.
  - 따라서 기능 명칭은 "이벤트"가 아닌 중립적 표현("배너" / "고정 게시글") 사용을 권장.
- 배너는 **여러 개** 노출 가능(가로 스크롤 캐러셀).

## 3. 범위

**포함**
- 배너 노출(캐러셀)
- 게시글 상세에서 배너 등록/해제
- 빈 배너 영역에서 게시글 선택해 연결
- 권한별 노출 분기
- 원본 글 삭제/비공개 시 예외 처리

**제외 (이번 작업 범위 외)**
- 배너 표시 **순서 변경** (추후 프로필 편집 화면에서 별도 처리 예정)
- 배너 카드 **시각 디자인** (본 문서는 기획·흐름만 다룸)

## 4. 기능 요구사항

### 4.1 배너 노출
- 프로필 페이지에 배너 영역을 둔다.
- 배너로 지정된 게시글이 1개 이상이면 가로 스크롤 캐러셀로 노출한다.
- 각 배너는 연결된 게시글을 나타내며, 탭 시 해당 게시글 상세로 이동한다.

### 4.2 배너 등록 / 해제 (글쓰기 권한자 전용)
두 진입점에서 동일한 "배너 노출 여부" 상태를 토글한다.

1. **게시글 상세 내 고정 토글**
   - 미고정 상태: "배너에 띄우기"
   - 고정 상태: "배너에서 내리기"
   - 같은 위치에서 on/off 토글로 처리(별도 해제 동선 불필요).
2. **빈 배너 영역의 "게시글 연결하기"**
   - 작성자의 게시글 목록을 띄워 선택 → 선택한 글의 배너 노출이 on 된다.

> 두 경로 모두 결과는 "해당 게시글의 배너 노출 = on/off"로 동일하다.

### 4.3 연결 동작
- 배너 탭 → 연결된 게시글 상세로 이동(게시글 목록 탭과 동일).

### 4.4 권한
- **배너 등록/해제(고정 토글), "게시글 연결하기" 버튼**: 글쓰기 권한 보유자(소유자, 권한 있는 멤버)에게만 노출.
- **방문자 / 권한 없는 사용자**: 배너는 읽기 전용. 탭 시 글 이동만 가능, 등록/해제 불가.

### 4.5 예외 처리
- 배너로 지정된 원본 게시글이 **삭제**되거나 **비공개**로 전환되면, 해당 배너는 배너 목록에서 **자동 제거**한다. (깨진 링크 방지)

## 5. 배너 영역 상태 정의

(빈 상태 + 권한 없음 → 섹션 숨김 규칙은 기존 게시판/리뷰 규칙과 동일)

| 상태 | 글쓰기 권한자 | 비권한자 / 방문자 |
|---|---|---|
| 배너 1개 이상 | 캐러셀 노출 + 각 글에서 고정/해제 가능 | 캐러셀 노출 (읽기 전용) |
| 배너 0개 | 빈 영역 + "게시글 연결하기" 노출 | 배너 영역 **숨김** |

## 6. 사용자 흐름

**A. 배너 등록 — 게시글 상세에서**
1. 권한자가 게시글 상세 진입
2. 고정 토글 "배너에 띄우기" 선택
3. 해당 글이 프로필 배너 영역에 노출

**B. 배너 등록 — 빈 영역에서**
1. 배너 영역의 "게시글 연결하기" 선택
2. 내 게시글 목록에서 글 선택
3. 선택한 글이 배너로 노출

**C. 배너 해제**
1. 배너로 지정된 글의 상세 진입
2. 고정 토글 "배너에서 내리기" 선택
3. 배너 영역에서 제거

**D. 방문자 열람**
1. 방문자가 프로필 진입
2. 배너 캐러셀 확인 → 탭 시 해당 게시글 상세로 이동
3. 배너가 없으면 배너 영역 자체가 보이지 않음

## 7. 데이터 / 구현 메모

- 게시글 모델에 "배너 노출" 불리언 플래그 추가(예: `is_banner`).
- 배너 목록 = 해당 프로필의 게시글 중 플래그 on이며 공개·미삭제 상태인 글.
- 별도 배너 엔티티 불필요. 배너 영역은 위 조건의 게시글을 조회해 렌더.
- 표시 순서/순서 변경은 본 PRD 범위 외. 현재는 단일 기본 노출만 하고, 순서 제어 필드는 추후 추가.
