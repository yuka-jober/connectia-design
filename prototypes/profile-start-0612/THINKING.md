# 명함 템플릿 온보딩 — 고민 중

## 제품 개요
- 서비스명: **Connectia**
- 짧은 프로필 페이지를 만들고, 방문자 질문은 AI가 답변해주는 서비스
- 홈 카피: *"단 1분만에 만들어보세요"*
- 템플릿 6종: **이력서 / 세일즈 / 서비스 소개서 / 프로필 페이지 / CS / 명함**

## 현재 온보딩 (모든 템플릿 공통)
사용자가 템플릿을 선택하고 `[이 템플릿으로 만들기]` 버튼을 누르면 페이지가 만들어지고, 그 위에 툴팁 기반 온보딩이 뜸:

1. **편집 툴팁** — 상단 [프로필 편집] 버튼을 하이라이트, "프로필 편집을 통해 자유롭게 페이지를 구성해보세요"
2. **설정 툴팁** — 상단 [설정] 버튼을 하이라이트, "자료 추가, 대화 설정, 통계 확인"
3. **알림 동의 카드** — 카카오 알림톡 수신 동의

→ 의도는 *"모든 템플릿에 동일한 통합 온보딩"*

## 새로 추가하려던 기능 (명함 한정)
**명함을 카메라로 촬영하거나 이미지 업로드해서 OCR로 자동 채우기.**
- 다른 템플릿에는 자동 채우기가 없음 (명함만 적용 가능한 기능)
- 현재는 `[프로필 편집]` 안에 들어가야 사용 가능

## 검토한 두 방향

### 방향 A — 페이지 생성 직후 스캔 단계 추가
`[이 템플릿으로 만들기]` → **스캔 시트(촬영/업로드/건너뛰기)** → **분석 중 화면(2.4초)** → 편집 툴팁 → 설정 툴팁 → 알림 동의

- 👍 "마법의 순간" — 본인 정보가 채워진 페이지를 보며 툴팁을 듣게 됨
- 👎 단계가 길어짐 (5단계)
- 👎 명함에만 적용되는 기능을 위해 전체 온보딩 흐름이 바뀜 → **통합 온보딩 원칙이 깨짐**

### 방향 B — 편집 툴팁 메시지를 자동 채우기 안내로 변경
기존 온보딩 흐름 유지, "프로필 편집을 통해..." 툴팁 문구를 **"내 명함을 찍어서 자동으로 채워보세요"** + [지금 스캔하기] CTA로 변경

- 👍 단계 추가 없음, 통합 온보딩 유지
- 👎 사용자가 [다음]을 눌러 그냥 넘길 확률 높음 → 스캔 기능 사용률 낮음
- 👎 결국 명함 템플릿에서만 다른 문구가 나오니, *완전한 통합*도 아님

## 진짜 고민 포인트

1. **명함만 자동 채우기가 있는데 이걸 위해 전체 흐름에 단계를 추가하는 게 맞나?**
   통합 온보딩이라는 원칙과 부딪힘.

2. **"이 템플릿으로 만들기 → 분석 → 툴팁 → 툴팁 → 알림"이 길고, "페이지가 만들어졌다"는 완료감이 모호함.**
   사용자가 *"지금 만들고 있는 중인가? 끝난 건가?"* 헷갈릴 수 있음.
   → 만들기 액션과 안내가 뒤섞여 있음.

3. **"1분만에 만들기" 카피와 부합하지 않음.**
   체감 단계가 너무 많음.

## 묻고 싶은 것
- 명함의 자동 채우기를 온보딩 흐름에 넣는 게 맞나, 아니면 페이지 안의 자연스러운 발견 지점에 두는 게 맞나?
- 통합 온보딩을 깨더라도 명함만의 특별 흐름을 만드는 것이 가치 있을까?
- "만들어졌다"는 완료감을 어떻게 줘야 사용자가 헷갈리지 않을까?
- 전체 흐름을 짧게 가져가면서 자동 채우기 기능 발견율도 챙기는 방법은?
